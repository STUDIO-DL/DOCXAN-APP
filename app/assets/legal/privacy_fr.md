# Politique de confidentialité de Docxan

**Brouillon pour publication.** Remplacer l’URL dans Play Console une fois hébergée.

Docxan numérise les documents sur l’appareil. L’OCR, la compression et le stockage quotidien sont locaux.

Si vous activez la sauvegarde, les fichiers sont chiffrés sur le téléphone (AES-256-GCM) avant d’être envoyés vers Cloudflare R2. Docxan ne peut pas lire le contenu de ces sauvegardes. Si vous oubliez le code PIN et n’avez pas d’autre méthode de récupération, la sauvegarde ne peut pas être restaurée.

Le compte (e-mail) est géré avec Supabase Auth. Nous ne vendons pas de données. Vous pouvez demander la suppression du compte et des blobs associés.

Contact : privacy@docxan.app
